# 雲端儲存設定教學

GodBook 可以把已下載的章節上傳到 **OneDrive 個人版**、**OneDrive 商業版**、**Google Drive** 或 **WebDAV**，並依照你選的策略刪除手機上的檔案以節省空間。閱讀只在雲端的章節時，App 會自動下載到暫存區。

OneDrive 與 Google Drive 需要你自己建立一組 **用戶端 ID**，填到 App 的「設定 → 下載 → 雲端儲存」。用戶端 ID 不是密碼：行動 App 屬於公開用戶端，登入時使用授權碼 + PKCE，不需要也不會儲存用戶端密鑰。

---

## OneDrive（個人版與商業版）

個人版和商業版可以共用同一個應用程式註冊。

### 1. 建立應用程式註冊

1. 用管理員帳號登入 [Microsoft Entra 系統管理中心](https://entra.microsoft.com)。
2. 「身分識別 → 應用程式 → 應用程式註冊 → 新增註冊」。
3. 名稱填 `GodBook`。
4. **支援的帳戶類型**選 **「任何組織目錄中的帳戶（任何 Microsoft Entra ID 租用戶 - 多租用戶）及個人 Microsoft 帳戶」**。
   - 只要商業版：選「僅此組織目錄中的帳戶（單一租用戶）」，並在 App 的「租用戶」欄位填你的租用戶網域（例如 `symphony.onmicrosoft.com`）。
5. 重新導向 URI 先不用填，按「註冊」。

### 2. 加入 iOS 平台

1. 進入剛建立的應用程式 →「驗證」→「新增平台」→「iOS / macOS」。
2. Bundle ID 填 `com.godbook.app`。
3. 確認產生的重新導向 URI 是 `msauth.com.godbook.app://auth`（App 的雲端儲存頁面也會顯示這個網址）。

> 用 AltStore / Sideloadly 側載時 Bundle ID 可能被改掉，但這不影響登入：重新導向 URI 仍然固定是上面這個網址。

### 3. API 權限

「API 權限 → 新增權限 → Microsoft Graph → 委派的權限」，加入：

| 權限 | 用途 |
|---|---|
| `Files.ReadWrite` | 讀寫你的 OneDrive 檔案 |
| `User.Read` | 顯示登入的帳號名稱 |
| `offline_access` | 取得重新整理權杖，不用每小時重新登入 |

### 4. 商業版（Microsoft 365 E3）的管理員同意

身為租用戶管理員，在「API 權限」頁按 **「代表 〈你的組織〉 授與管理員同意」**，租用戶內的使用者登入時就不會再看到同意畫面，也不會因為「使用者不可自行同意」而被擋下。

另外檢查兩件事：
- **條件式存取**：如果有「需要合規裝置」或「需要核准的用戶端 App」這類原則，未簽章、側載的 GodBook 會被擋下。請把 GodBook 排除在這些原則之外，或另外建立允許它的原則。
- **OneDrive 已啟用**：帳號需要有 OneDrive 授權，而且至少開過一次 OneDrive（E3 預設包含）。

### 5. 填到 App

- 「應用程式（用戶端）識別碼」貼到 **OneDrive 個人版** 和 **OneDrive 商業版** 的「用戶端 ID」欄位（同一個註冊可以兩邊都填）。
- 商業版的「租用戶」欄位：
  - 多租用戶註冊：保留 `organizations`。
  - 單一租用戶註冊：填租用戶網域或租用戶 ID。
- 按「連結」，在系統登入頁選擇帳號即可。

## Google Drive

### 1. 建立專案與啟用 API

1. 到 [Google Cloud Console](https://console.cloud.google.com) 建立新專案（例如 `GodBook`）。
2. 「API 和服務 → 程式庫」，搜尋並啟用 **Google Drive API**。

### 2. OAuth 同意畫面

1. 「API 和服務 → OAuth 同意畫面」（新版介面叫「Google Auth Platform」）。
2. 使用者類型選 **外部**，填 App 名稱與支援電子郵件。
3. 範圍（資料存取）加入 `https://www.googleapis.com/auth/drive.file`。
   - 這個權限只讓 GodBook 看到它自己建立的檔案，屬於非敏感範圍，**不需要送交 Google 審查**。
4. **發布狀態要改成「實際運作中」（正式版）**。
   - 停留在「測試中」時，只有加入測試使用者名單的帳號能登入，而且登入每 **7 天**就會失效。

### 3. 建立 iOS 用戶端

1. 「憑證 → 建立憑證 → OAuth 用戶端 ID」。
2. 應用程式類型選 **iOS**，套件 ID 填 `com.godbook.app`。
3. 建立後複製用戶端 ID（格式為 `123456-xxxx.apps.googleusercontent.com`），貼到 App 的 **Google Drive** 欄位，按「連結」。

重新導向 URI 會自動由用戶端 ID 推算，例如 `com.googleusercontent.apps.123456-xxxx:/oauthredirect`，不需要另外設定。

## WebDAV（NAS、Nextcloud 等）

在「設定 → 進階 → 快取、備份與 WebDAV」填好網址、帳號、密碼，再到「雲端儲存」的 WebDAV 按「連結」。章節會放在該網址底下的雲端資料夾（預設 `GodBook/`）。

---

## 雲端上的檔案結構

存放資料夾預設是 `GodBook`，可以在「雲端儲存 → 上傳 → 雲端資料夾」改成別的名稱，也可以用 `/` 建多層（例如 `漫畫/GodBook`）。

- 改了資料夾之後，已上傳的章節會留在原本的資料夾並照常讀取；之後上傳的才會放到新資料夾。
- 「從雲端還原下載清單」讀取的是**目前設定**的資料夾裡的 `index.json`。換裝置時，請先把資料夾設成和舊裝置相同。
- Google Drive 使用 `drive.file` 權限，GodBook 只看得到自己建立的資料夾。你在網頁上手動建立的同名資料夾，GodBook 看不到，會另外建一個。

```
<雲端資料夾>/
├── index.json                 下載清單（換裝置時用來還原）
└── Comics/
    └── <來源>_<作品 ID>/
        ├── cover.jpg
        └── ch_<章節 ID>.cbz   每話一個 CBZ（不壓縮的 ZIP），可直接用其他閱讀器開啟
```

## 本機保存策略

| 策略 | 行為 |
|---|---|
| 永遠保留本機（預設） | 雲端只當備份，不會自動刪除手機上的檔案 |
| 上傳後刪除本機 | 上傳並確認檔案大小一致後，立即刪除手機上的圖片 |
| 只保留最近幾話 | 保留目前閱讀位置起的 N 話，其餘已上傳的章節只留在雲端 |
| 空間不足時才釋放 | 手機剩餘空間低於門檻時，從最久沒讀的作品開始釋放 |

- 預設策略在「雲端儲存」設定；每部作品可在「書庫 → 下載」長按另外指定。
- 只有**已上傳且確認大小一致**的章節才會被刪除。作品的詳情與封面會保留在手機上。
- 「從雲端下載回本機」的章節會暫時保留，不會被保存策略自動刪除，作品原本的策略也不會被改動。不需要時，在作品詳情頁點章節右側的圖示逐話「釋放本機空間」或「刪除本機下載」，或用「釋放全部本機空間」整部釋放。

## 換裝置

1. 在新裝置連結同一個雲端帳號（登入權杖不會放進 App 備份，必須重新連結）。
2. 確認「雲端資料夾」和舊裝置設定的相同。
3. 按「從雲端還原下載清單」，作品會以「僅雲端」的狀態出現在下載列表。

## 常見錯誤

| 訊息 | 原因與處理 |
|---|---|
| `AADSTS50011`（redirect URI 不符） | iOS 平台的 Bundle ID 不是 `com.godbook.app`，或沒有加入 iOS 平台 |
| `AADSTS50194`（不是多租用戶應用程式） | 單一租用戶註冊卻用 `organizations` 登入；在「租用戶」欄位填你的租用戶網域 |
| `AADSTS700016`（找不到應用程式） | 用戶端 ID 貼錯，或帳戶類型沒有包含要登入的帳號（例如沒勾個人帳號） |
| `AADSTS65001` / 需要管理員核准 | 租用戶不允許使用者自行同意；請管理員授與管理員同意 |
| `AADSTS53000` / `53003` | 被條件式存取擋下，見上方商業版說明 |
| Google `Error 403: access_denied` | 應用程式還在「測試中」，而且這個帳號不在測試使用者名單 |
| Google 每週都要重新登入 | 發布狀態仍是「測試中」，改為「實際運作中」 |
| Google `Error 400: invalid_request`（不允許自訂 URI 配置） | 到該 iOS 用戶端的「進階設定」勾選「啟用自訂 URI 配置」 |

## 限制

- iOS 只允許 App 進入背景後短暫繼續上傳。章節很多時，請讓 GodBook 停留在前景直到上傳完成。
- 預設只在 Wi-Fi 上傳；可以在設定中關閉。
